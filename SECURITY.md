# Security Policy

## Supported versions

Only the latest deployed version on `harness-market-ds.refertur.net` is supported.

## Reporting a vulnerability

Please report security issues privately via email to the maintainers (see repository contact). Do not open public issues for vulnerabilities.

We aim to acknowledge within 72 hours and provide a fix or mitigation within 14 days.

## Scope

- The catalog site and its build/deploy pipeline.
- Security scanning of listed plugins (see `/security/` on the site).

## Out of scope

- Vulnerabilities in third-party plugins themselves (report to plugin authors; we will mark status on the site).
- Vulnerabilities in DeepSeek Harness core (report to upstream).

## Disclosure

We follow responsible disclosure. After a fix is deployed, we publish a security report on the site.
