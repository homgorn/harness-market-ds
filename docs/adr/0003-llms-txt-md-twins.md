# ADR-0003: llms.txt strategy and .md twins

**Date:** 2026-11-11
**Status:** accepted

## Context
Answer engines (ChatGPT/Claude/Perplexity/Google AI Overviews) need
machine-readable summaries and stable page identifiers to cite a source.

## Decision
- `public/llms.txt` — curated summary: what the catalog is, page types,
  languages, top artifacts, how to cite. Updated manually on content changes.
- `public/llms-full.txt` — full machine dump (~1.4 MB, 10,624 lines,
  `slug | kind | name | category | risk | install`). Generated by
  `scripts/build-llms.mjs` from `data/catalog.ssr.json`.
- Per-page Markdown twins `/<type>.md` (FAQ, Docs, Security, About, Legal,
  Blog, Changelog) served via `src/pages/[type].md.ts` — same build, ~9 extra
  files. Plugin detail Markdown twins are deliberately not built: they would
  add ~10,600 files per locale and blow Cloudflare's per-version asset cap.

## Consequences
- Answer engines can ingest the corpus from one file; queries about "is this
  plugin safe" resolve via `security.md` + `llms-full.txt`.
- No 404 for missing `.md` twins of plugin pages — this is intentional.
- If future scale requires `.md` twins for all pages, chunk them into R2.
