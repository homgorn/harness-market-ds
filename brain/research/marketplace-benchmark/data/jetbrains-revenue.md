# JetBrains Marketplace Revenue Sharing - Raw Fetch
URL: https://plugins.jetbrains.com/docs/marketplace/revenue-sharing-and-fees.html
Date: 2026-11-11

## Revenue Sharing Model
- 15% commission on all plugin sales via JetBrains Marketplace
- Deducted from sale price before transfer to developer
- Reason: sustainability + reinvestment in plugin ecosystem
- Commission rate can change with 1-month notice, capped at 25%
- High-revenue plugins: custom formula negotiation possible
- No additional fees for developing/listing extensions

## Share Calculation
- Reseller fee: % kept by reseller (from JetBrains commission)
- JetBrains commission: 15% (standard)
- Developer's share: amount vendor receives

## Payouts
- Per Developer Agreement rules
- Paid plugins: 30-day free trial
- Licensing API: check if user has license (email-based)

## History
- 5% intro rate until July 2020
- Standard 15% since July 1, 2020
- One Year of Paid Plugins blog (July 2020)

## Billing & Licensing
- Same sales processes as JetBrains products
- On-premises License Server supported
- Reseller/distributor network (vendor opt-in)
- Externally-paid model: vendor manages own licensing

## Monetization Models
1. Free: donations accepted
2. Freemium: free features + paid license (30-day trial)
3. Paid: all features paid, 30-day trial only
4. Externally paid: vendor's own licensing solution

## Sales Report
- Transactions: new purchases, renewals, discounts
- Fields: Date, Amount (incl. commission), Customer Code, Country, Name (org only), Period (Monthly/Annual), Reseller, Ref Num
- Freemium plugins, special coupons from developers
