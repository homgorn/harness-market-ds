# WordPress.org Plugin Directory - Raw Fetch (Search Results)
URL: https://wordpress.org/plugins/
Date: 2026-11-11

## Statistics
- 59,000+ free plugins (reported 2021, Wikipedia)
- ~60,000 plugins (reported 2025-2026)
- 409M people view 20B pages/month on WordPress
- 200+ languages
- 5,200 paid plugins on ThemeForest (separate)

## Taxonomy
- Tags (keywords) - primary classification
- No official categories (uses tags)
- "Popular", "Beta", "Blocks" views
- Plugin Tag archives: /plugins/tag/name/
- Author archives: /plugins/author/name/

## Search Ranking (ElasticSearch, open source)
Weighting factors:
1. Keyword in: title, excerpt, description, tags, author
2. Rating
3. Support threads closed
4. Active installs
5. Recency: lose rank if not updated within 180 days or 0.4 WP versions

## Monetization
- Zero platform fees
- Freemium dominant: lite on .org → pro off-site
- SaaS addons, affiliate, WooCommerce extensions
- Freemius platform for licensing/billing
- "Premium plugins convert up to 30% of active installs" - WP Minute

## Trust/Security
- Automated code scanning (Plugin Check)
- Human review for new submissions
- "Tested up to: X.Y" version badge
- Active install count
- Last updated date
- Support forum threads

## SEO
- Core sitemap: /wp-sitemap.xml includes all plugin pages
- Tag archives indexable
- Author archives indexable (can be noindexed)
- ElasticSearch ranking
- Clean URLs: /plugins/plugin-name/
- Structured data on plugin pages

- Powered by WordPress (wp-admin for management)

- Localized sites with translated plugin descriptions
