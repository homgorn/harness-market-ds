# Chrome Web Store Discovery - Raw Fetch
URL: https://developer.chrome.com/docs/webstore/discovery
Date: 2026-11-11

## Categories
- Categories organize items by main function
- Examples: Shopping, Education, Just for Fun
- Assign via Developer Dashboard → Store Listing → Product Details

## Search
- Key tool for user discovery
- Ranking based on: metadata from listing page
- Complete, accurate, optimized listing = better discoverability

## Collections
- Curated by editors
- "Write great software", "Make listing look nice", "Promote independently"
- Solicitations not accepted

## Monetization (Historical)
- Chrome Web Store Payments: 5% transaction fee (shut down Feb 2021)
- No replacement since
- Developers self-host: Stripe, Lemon Squeezy, ExtensionPay
- Ads/affiliate/freemium models

## Monetization Reality (BigIdeasDB)
- 57.1% of tracked extensions earn $0/mo
- 6.3% clear $1,000/mo
- Average monthly revenue: $295
- Highest in set: $9,742/mo
- Consumer-facing: 56, Business-facing: 13
- Freemium conversion ~3-5%
- Subscription model: 1.8% of paid extensions, avg $3.99/mo or $29.99/yr
- One-time purchase: 0.7% of paid extensions
