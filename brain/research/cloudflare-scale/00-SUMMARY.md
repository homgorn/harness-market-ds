# Cloudflare Scale Research — Executive Summary

**Recommendation**: Deploy the 72,576-page catalog (10,368 plugins × 7 languages) as a **single Workers Static Assets project on the Workers Paid plan ($5/month)**. This architecture natively supports the 100,000-file limit (our ~85-90k files fit with headroom), serves static assets free and unlimited, handles SSR for dynamic plugin data at the edge, and uses subdirectory URL structure (`/en/plugin/...`, `/de/plugin/...`) on one custom domain — Google's preferred hreflang implementation. All 7 languages deploy atomically via `wrangler deploy`, roll back instantly, and share link authority. At 2M visits/month, total cost stays under $10/month (base $5 + negligible CPU/KV overages). The Workers platform is Cloudflare's strategic convergence target (Pages auto-migration confirmed by Tech Lead Kenton Varda), making this future-proof. Alternatives fail: Workers/Pages Free caps at 20k files; R2/KV add operational complexity and per-request costs; multi-Worker subdomain split fractures SEO authority and hits per-Worker request limits; external hosts (GitHub Pages 1GB, Netlify 15GB, Vercel 15k source files) cannot accommodate the file count or bandwidth.
